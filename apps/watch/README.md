# Trophy Watch: post-game analysis (Agent 1 UI, Agent 3 data)

Post-game analysis for **every game we run this weekend** (live ping pong + recorded basketball), at `/watch/{game_id}`. It translates Replay's Fire TV features to the web: recap, seek bar with moment notches + sprite preview, moments with filters, highlights + ★ Play of the game, condensed game, replay with overlays, stats (bounce heatmap / shot chart), voice search over moments (Moss). If time allows: broadcast mode with Cartesia play-by-play, coach tips, review queue, follow a player, clip + share, a Spacetime watch party.

The full feature map is in `docs/plan/trophy-watch-postgame.md`; the contracts are in `docs/plan/interfaces-v1.md` §19. Vendor Replay `packages/tv-core` (MIT notice kept). Never copy Replay's `docs/media/` or `samples/real/`.

## As built (2026-10-24, Agent 1): the PG-MUST slice
- `npm run dev -w @trophy/watch` (port 5175, in `make dev`; Caddy routes `/watch/`). Open `/watch/?g=<game>&k=<join key>` (joins as `viewer`), or `/watch/?demo=table_tennis` for the labelled-synthetic MockState game.
- **Recap:** final score, ★ Play of the game (with the storyboard-sprite thumbnail when there's a recording, and its `reasons`), and **Play full game · Highlights · Condensed · Stats**.
- **Player:** the recorder's HLS through hls.js (native HLS only without MediaSource). Game time = media time + the camera's `t0_game_s`. Without a recording, a virtual clock drives a reconstructed top-down view (ball trail + this rally's bounces), badged "reconstructed from tracking, not video". The vendored tv-core media clock drives the overlays; a 250 ms timer also runs playlist control, so a hidden tab still stops at a clip's end.
- **Seek bar:** moment notches (tall = points, short = faults/edges, diamond = bookmarks, accent = Play of the game), the playhead, and a hover preview from the recorder's storyboard sprite. Keys: Space, ←/→ 5 s, J/L previous/next moment, S slow-mo (1×/0.5×/0.25×), `,` `.` frame step.
- **Moments** with filters (Points, Serve faults, Edge balls, Challenges, Rallies > 8 shots, Bookmarks). **Highlights** = top `highlight_score` in game order, ending on the Play of the game. **Condensed** = each rally −0.5 s/+1 s, merged.
- **Replay card:** the moment's call (tier, p, why), the AI second opinion labelled **uncalibrated**, the serve-toss side view (16 cm line, 30° cone on the rise, D-31) and commentary lines.
- **Stats** (labelled auto-detected): points, on serve / receive (when server data exists), serve faults, edge balls, longest rally (bounces), bounce map; anything not detected says "not detected", never 0.
- **Search:** keyword search over moments, labelled as such. Moss semantic search (`/search_moments`) isn't connected; the rules service isn't on main.
- **Verified on the Windows PC:** the synthetic demo (recap, notches, highlights, replay card with votes and commentary, toss trace, stop at the clip's end), and a recorded game (20 s of the CC BY clip through gateway → recorder, plus synthetic moments via `upsert_moment`): HLS plays at 1280×720, moments seek to the right media time and stop at the clip's end, the sprite thumbnail loads. Not yet: a phone-sized screen, a finished (ENDLIST) game, real engine moments.
- **Not built yet (PG-SHOULD):** follow cam, player card, coach tips, review queue, broadcast mode with Cartesia, clip + share, open on another screen, watch party.
