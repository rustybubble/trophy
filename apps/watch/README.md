# Trophy Watch: post-game analysis (Agent 1 UI, Agent 3 data)

Post-game analysis for **every game we run this weekend** (live ping pong + recorded basketball), at `/watch/{game_id}`. It translates Replay's Fire TV features to the web: recap, seek bar with moment notches + sprite preview, moments with filters, highlights + ★ Play of the game, condensed game, replay with overlays, stats (bounce heatmap / shot chart), voice search over moments (Moss). If time allows: broadcast mode with Cartesia play-by-play, coach tips, review queue, follow a player, clip + share, a Spacetime watch party.

The full feature map is in `docs/plan/trophy-watch-postgame.md`; the contracts are in `docs/plan/interfaces-v1.md` §19. Vendor Replay `packages/tv-core` (MIT notice kept). Never copy Replay's `docs/media/` or `samples/real/`.
