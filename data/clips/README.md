# Clips

`clips.yaml` is the manifest (URL, license, what each clip shows, segments, expected calls). Fetch clips locally or on a VM; keep large/private media in ignored storage or access-controlled object storage. Small licensed, non-sensitive test fixtures may be versioned when useful. `credits.json` supplies demo and shared-video credits. CC BY / CC0 are convenient defaults; other footage is welcome when permissions cover the intended use. Confirm † licenses before reuse. See [media guidance](../../docs/rules-compliance.md).
