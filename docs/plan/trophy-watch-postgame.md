# Trophy Watch: post-game analysis for every game (ping pong + basketball)

*Planning lead, 2026-10-24. Source: a direct read of Replay's Fire TV app (`apps/tv/src`, ~13k lines) and `packages/tv-core` at commit `2db92c0` (MIT), plus `docs/fire-tv.md` and its README. This doc translates every Fire TV feature to Trophy's stack: a **web app** (Vite 7 + React 19 + strict TS at `/watch/`, any browser, phone or TV via cast/HDMI), **Spacetime** (metadata only), the **recorder** (video) and our services. Contracts are in [interfaces-v1.md](interfaces-v1.md) §19.*

## 0. What changes from Fire TV to the web
- **Input:** Replay's D-pad layer (`input.ts`, `platform/keys.*`, `focus/spatial.ts`, the `useDpad` stack) is **dropped**. Use pointer, touch and keyboard: ←/→ seek, J/L jump to the previous/next moment, Space pause, F follow, S slow-mo, M moments. A remote isn't needed, because phones and laptops are the TV.
- **Rendering:** React Native `View`/`StyleSheet`/`Animated` → DOM + CSS transforms. Replay's own web build (`apps/web` `/tv/*`, `main.web.tsx`, `Media.web.tsx`) already does this for several screens, so start from those.
- **Data:** Replay's Lambda API and S3 jobs → **Spacetime subscriptions** (moments, calls, rallies, scores, observations, players) + the **gateway watch API** (video HLS, tracks, clips, sprites) + the **rules service** (search, tips).
- **"On your phone" QR codes** (typing and edits went to the phone because a TV can't type) → **not needed**: the web app *is* on the phone. Keep one QR: "open this game on another screen" (a scoped, expiring token).
- **Vendored as-is** (MIT notice kept; recorded in `docs/licenses.md`): `packages/tv-core/src/{types,follow,clock,retry,display,replays}.ts` → `apps/watch/src/vendor/tv-core/`. `discovery.ts` is adapted, because its routes differ.
- **Never copy** Replay's `docs/media/` or `samples/real/` (real people).

## 2. Which tier ships when
- **PG-MUST**, the "Trophy Watch core", starts when Agent 1's live MUSTs pass C3:
  - recap page;
  - seek bar with notches + sprite preview + J/L;
  - moments list with filters;
  - highlights reel + ★ Play of the game with reasons;
  - condensed game;
  - replay any moment with overlays and votes;
  - stats with heatmap and shot chart;
  - search by text or voice (Moss).
  - **It works for both the live ping-pong game and the recorded basketball clip.**
- **PG-SHOULD:** reconstructed top-down views, basketball follow-a-player + player card + naming, coach tips, review queue, broadcast mode with Cartesia commentary, clip + share, open on another screen, watch party.
- **PG-STRETCH:** multi-angle cuts, 9:16 export, ping-pong ball cam.
- **LATER:** SAM 2.5D free view and player's view, face profiles, blur for shared clips.

## 3. Why this helps the prize tracks
- **Spacetime:** moments, the watch party and synced reactions make it "multiplayer shared state".
- **Moss:** voice search over moments, alongside ask-the-ref.
- **Cartesia:** broadcast mode with spoken play-by-play.
- **Anthropic:** grounded coach tips plus the validator, an honest account of where the model can go wrong.
- **Meta:** watching and sharing the game together.
- **Overall:** "it doesn't just referee, it gives you the broadcast afterwards."
