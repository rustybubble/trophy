## PR 2 — recorder and replay (`a2/recorder-replay`, stacked on PR #10)

Adds a Redis frame-bus recorder with actual encoder probing, 2-second fMP4 HLS, per-source-frame index/JPEGs,
10×10 storyboards, calibration and track copies. End-game control commands drain retained frames before
finalization. Capture gaps and held video frames are explicit; source crops never use fabricated frames.
Existing archives are not overwritten. Crash resume is not implemented.

Gateway adds authenticated replay clips, projected overlays/one-sigma ellipses, service-only voter crops,
Watch manifest/HLS/sprites and normalized `replay.tracks.v1` tracks. Missing calibration yields warnings;
nonplanar projection requires a usable undistorted pose. New Watch ctl commands now traverse gateway
validation. `clip_as_phone.py` supports isolated endpoints and checks the replay routes without logging tokens.

Measured locally on the Mac with existing, user-supplied recordings (not newly acquired media):

| Input | Stream/index/HLS frames | Gateway rate | Replay MP4 | Voter crops | Largest base64 crop |
|---|---|---|---|---|---|
| side, source 5–13 s | 240 / 240 / 240 | 30.0 fps | 369,853 bytes | 4 | 117,280 bytes |
| diagonal, source 5–13 s | 240 / 240 / 240 | 30.0 fps | 311,649 bytes | 4 | 122,612 bytes |

Both HLS archives decode at 1280×720, finalize with no encoder error or held frames, and return HLS HTTP 200.
Tracks were empty and calibration unavailable in these real-footage transport runs: no tracker or geometry
accuracy is claimed. Separate synthetic tests cover nonempty tracks, covariance projection, privacy boundaries
and capture gaps. 7 recorder integration/unit tests and all 15 gateway tests passed; focused Ruff checks passed.
The existing HQ-upload route accepted the original segments, but optional ffprobe metadata was unavailable.
Windows encoder throughput and phone-on-LAN latency have not been tested here. Outputs/reports stay ignored
under data/local/recordings/. User approval is required before merging this gateway PR.

Automatic match completion is also monitored from Spacetime on a background read-only connection. A local
synthetic integration test confirmed that an engine-only `status: ended` update finalizes HLS without a
gateway control command. HTTP reads do not block the frame bus.
