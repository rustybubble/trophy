## Spike findings (Spacetime 2.13.0, verified)
- `POST /v1/database/{db}/call/{reducer}`; body = positional args array or an object keyed by arg names; 200 with an empty body on success; a `SenderError` returns **530**.
- **Unauthenticated calls succeed with a fresh random identity**, so every writing reducer must check `ctx.sender` against a registered service identity. The pattern (store the publisher's identity in `init`, compare in the reducer) was verified.
- The generated TS client uses camelCase fields (`row.sentMs`); the module and HTTP use snake_case.
- `onInsert` fires for pre-existing rows when a subscription is applied.
